
# SMIT Batch 22 – JavaScript Assignment 01

## About the Project
This project contains 12 JavaScript questions completed as part of the SMIT Batch 22 JavaScript Assignment 01.

The assignment focuses on JavaScript fundamentals, variables, data types, mathematical operations, calculations, and problem-solving.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Open the browser Developer Tools.
5. Navigate to the Console tab.
6. View the JavaScript output.
